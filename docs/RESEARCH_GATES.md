# MORSE Research Gates

## Gate 0 — Apparatus integrity

Required before interpreting any experimental result:

- source commit identified;
- configuration identified;
- deterministic seed recorded;
- observation identity unique;
- expected matrix cardinality validated;
- evidence digest reproducible;
- test suite green.

## Gate 1 — Mechanism comparison

Compare the controlled synthetic regimes across 3- and 4-leaf topologies. This establishes only modeled mechanism behavior.

## Gate 2 — Baseline comparison

Compare MORSE against resource-matched conventional scheduling and communication baselines. Require predeclared outcomes and stopping rules.

## Gate 3 — Controlled AI pilot

Only after Gates 0–2 support the mechanism should external-model evaluation be considered. Freeze model versions, prompts/protocols, budgets, seeds, evaluation criteria, and authorization before execution.

## Gate 4 — Independent replication

A favorable internal result is insufficient for a strong general claim. Reproduce the result independently with preserved provenance.

## Gate 5 — Publication claim

Publication or public claims must distinguish implementation evidence, synthetic evidence, controlled AI evidence, and independent replication. Novelty claims require a fresh literature review and appropriate expert/legal review where applicable.

## Current position

Gate 0 apparatus implementation is substantially complete and has passed the current CI test matrix. Gate 1 execution remains the next empirical step. Gates 2–5 are not yet satisfied.
