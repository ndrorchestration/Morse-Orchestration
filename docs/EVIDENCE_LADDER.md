# MORSE Evidence Ladder

| Level | Meaning | What it can support |
|---|---|---|
| L0 | Conceptual | Design idea only |
| L1 | Specified | Formal hypotheses/protocol |
| L2 | Implemented | Existence of executable apparatus |
| L3 | Deterministically verified | Correctness against defined invariants |
| L4 | Fault-tested | Observed behavior under controlled faults |
| L5 | Synthetic comparative | Mechanism-level comparative observations |
| L6 | AI empirical | Results from actual model/provider runs |
| L7 | Independently replicated | Reproduction by an independent execution |

## Current MORSE position

The repository contains L2/L3 apparatus and comparative scaffolding. L4/L5 require execution of the corresponding fault and synthetic experiments. L6 has **not** been established. AI efficacy empirical N remains 0.

## Claim discipline

Passing tests establish implementation properties. They do not establish performance superiority. A statistically significant result establishes evidence for the tested comparison and endpoint; it does not establish universal superiority or causal generalization beyond the experimental scope.
